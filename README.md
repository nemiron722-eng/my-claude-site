# Konstantin Design

Сайт-портфолио графического дизайнера: реклама, полиграфия, презентации, выставки, web.

## Структура

```
index.html        разметка страницы
css/styles.css    стили и дизайн-токены (цвета, радиусы, шрифты в :root)
js/main.js        скрипты: услуги, счётчики, меню, лента логотипов
assets/img/       работы для кейсов и hero
assets/logos/     логотипы клиентов
build.py          сборка в один HTML-файл (dist/, в репозиторий не попадает)
```

## Запуск

Сайт статический. Откройте `index.html` в браузере или включите GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

Единый файл со встроенными картинками, стилями и скриптом: `python3 build.py` → `dist/konstantin-design.html`.

## Что заменить

- Фото в блоке «Обо мне» (сейчас заглушка)
- Контакты: `mail@gmail.com`, `Telegram: @username`
- Цифры в блоках «10+», «150+», «40+» (примерные)
- Подписи к кейсам прочитаны с макетов, проверьте написание
- Примеры для услуги «Web»
