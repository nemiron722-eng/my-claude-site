# Варианты оформления

- `/` — исходный синий вариант
- `variants/light/` — светлый яркий вариант (оранжевый акцент)
- `variants/apple/` — вариант в стиле Apple.com
- `variants/taste/` — вариант по правилам taste и Impeccable: заголовок с профессией, плоские цвета, без подписей и анимации

Каждый вариант самодостаточен: откройте `index.html` или соберите один файл через `python3 build.py`.
