# Konstantin Design · Apple direction

Новая редакция портфолио в минималистичной эстетике: крупная типографика, большие изображения, свободное пространство, контрастные светлые и тёмные разделы.

## Просмотр
Откройте `index.html` в этой папке или опубликуйте ветку `portfolio/apple-redesign` через GitHub Pages для предпросмотра.

## Структура
- `index.html` — главная страница.
- `css/styles.css` — дизайн-система, адаптивная сетка и стили кейсов.
- `js/main.js` — мобильная навигация и поведение формы.
- `cases/` — отдельные страницы девяти проектов.
- `assets/img/` и `assets/logos/` — визуальные материалы.

## Что нужно подтвердить перед публикацией
- Заменить блок-заглушку на портрет.
- Добавить рабочий email и Telegram; подключить форму.
- Сверить названия, авторство и содержание каждого кейса.
- Добавить реальные визуалы презентаций и рекламных кампаний. В текущем наборе изображений отдельные полноценные кейсы этих направлений отсутствуют, поэтому они не выданы за готовые проекты.
- Проверить, какие логотипы клиентов можно публично показывать, и добавить только подтверждённые.
- Уточнить цифры и формулировки опыта, не использовать неподтверждённые показатели.
